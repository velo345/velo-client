For developers

One API.
Everything above.

Every tool is a plain HTTPS endpoint under velo-client.com/v2. No key for light use; a free key from your Velo account raises the limits, Velo+ raises them again. Repeated requests are served from cache and cost nothing.

# a player in a walking pose, 512 px, with 3D skin layers

# server status, MOTD as MiniMessage, legacy and HTML
curl "https://velo-client.com/v2/server/hypixel.net"
