Features

Everything you'd install five mods for

Built in, designed to work together, and every setting is saved per profile.

Performance

More frames, fewer stutters

Performance Boost presets with live sliders and adaptive render distance. Render Culling skips far-away holograms, item frames and chests, which is where lobby lag comes from. Shader Cache makes startup and resource reloads faster. The launcher also adds Sodium, Lithium, FerriteCore, EntityCulling and ImmediatelyFast where they're available.

HUD

A HUD that arranges itself

FPS, ping, coordinates, armor, potions, keystrokes, minimap, scoreboard and more. Modules stack into the corners automatically, and you can drag anything wherever you like.

Social

Friends on every server

See where your friends are playing, chat with them, and join them with one click. It works in game (press O) and in the launcher, with popups you can tune or mute.

Waypoints

Never lose your base

Waypoints with icons and colours, separate lists per world and dimension, automatic death points, and sharing with friends.

Queues

Background Queue

Wait in a long server queue while you play somewhere else. Velo shows your position and switches you over when it's your turn.

Quality of life

The small things, done right

  • Auto Reconnect with a countdown that stops once you leave the screen
  • Session Fixer refreshes an expired login and reconnects you
  • Zoom, Free Look, toggle sprint and sneak
  • Custom crosshair editor with an attack-charge indicator
  • Command keybinds: one key for /home
  • Schematics browser for Litematica and WorldEdit
Launcher

A launcher you'll actually enjoy opening

Sign in with Microsoft, pick a profile and connect. Velo handles Fabric, mods and memory for you.

  • Profiles for every server or modpack, each with its own mods, resource packs and shaders
  • Modrinth built in: add mods, Update all in one click, old files are kept as backups
  • Automatic RAM that leaves room for your PC, so heavy modpacks don't push it into swap
  • Servers with live ping and player counts, and a launch profile for each server
  • Your profile: play time, sessions and stats from your worlds
  • Open the same profile twice, for example for an alt account
Cosmetics

  • Live 3D preview on your own skin, in game and in the launcher
  • Works together with Wavey Capes
  • Kill effects and a growing store of designed capes

FAQ

Questions

Is Velo Client free?

Yes. The client, the launcher and every module are free. Velo Coins only buy cosmetic capes, and you can earn them by playing.

Can I use it on servers like Hypixel?

The modules are mostly visual and quality-of-life features. Every server has its own rules, so check them before you join. Server-specific tools can be turned off per profile, and each module shows how safe it is to use.

Does it work with Sodium, Iris and my other mods?

Yes. Velo is a normal Fabric mod. The launcher can install Sodium, Lithium and other performance mods for you, and you can add anything from Modrinth to each profile.

Do I need the launcher?

No. The launcher is the easiest way to play, but the mod jar also works with the vanilla launcher, Prism, MultiMC or any other Fabric setup. Friends and capes sync either way.

Is my Microsoft account safe?

Sign-in uses Microsoft's own device-code login. Your password never touches Velo. The Velo Network checks who you are the same way Minecraft servers do, so it never receives your access token.

Which Minecraft versions are supported?

{{minecraft.version}}. Each version has its own jar, and the launcher picks the right one automatically.
